# Runink River adopters

Organisations and projects that use Runink River, or build on it, and have agreed to say
so in public.

**No adopters are listed yet.** Runink River has not published its first signed release,
and this list stays empty until someone adds themselves. The project does not list anyone
who has not asked to be listed.

## Add yourself

Open a pull request that adds one row to the table below, signed off like any other
contribution ([CONTRIBUTING.md](CONTRIBUTING.md#developer-certificate-of-origin-dco)). The
person opening it should be able to speak for the organisation. A maintainer may ask for a
public link that confirms the use before merging.

| Organisation or project | How it uses Runink River | Since | Contact or link |
| --- | --- | --- | --- |
| | | | |

How it uses Runink River can be short: "developer workstations for our data team",
"base for our own distribution, built with an external profile", "the `linux-runink`
kernel from the AUR on our build hosts".

## Downstream distributions

Distributions built from this repository with an out-of-tree profile
([docs/BUILD.md](docs/BUILD.md), "Downstream distributions") are welcome in the same table.
Listing one does not mean the project endorses it or supports it; its vendor does
([SUPPORT.md](SUPPORT.md), [TRADEMARKS.md](TRADEMARKS.md)).

To remove an entry, open a pull request or ask a maintainer.
