# Getting help with Runink River

- **Installing and running it:** start with [README.md](README.md), then
  [docs/INSTALL.md](docs/INSTALL.md) and [docs/INSTALLER-HARDWARE.md](docs/INSTALLER-HARDWARE.md),
  or the documentation site at <https://docs.runink.org/river/>.
- **Building it:** [docs/BUILD.md](docs/BUILD.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Questions and ideas:** ask in [GitHub Discussions](https://github.com/org-runink/river/discussions)
  (the Q&A category for questions, Ideas for proposals you want feedback on).
- **Bugs and agreed feature work:** open a GitHub issue in this repository. For a bug,
  include the version (`/etc/runink-os-version`), the hardware, what you expected and what
  happened, and remove hostnames, addresses and credentials from any logs
  ([CONTRIBUTING.md](CONTRIBUTING.md#reporting-bugs)).
- **Security problems:** never in public. Follow [SECURITY.md](SECURITY.md).
- **Code of Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is best effort by the maintainers in [MAINTAINERS.md](MAINTAINERS.md) and by other
contributors. There is no mailing list or chat channel yet; when one exists it will be
listed in [README.md](README.md#community-and-communication). Applications and platforms
that others ship on Runink River as downstream payloads are supported by their vendors, not
here.
