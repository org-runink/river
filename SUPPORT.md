# Getting help with Runink River

- **Installing and running it:** start with [README.md](README.md), then
  [docs/INSTALL.md](docs/INSTALL.md) and [docs/INSTALLER-HARDWARE.md](docs/INSTALLER-HARDWARE.md).
  On the install medium, `river-guide` answers questions about the install guide offline
  ([docs/INSTALL-GUIDE-AGENT.md](docs/INSTALL-GUIDE-AGENT.md)).
- **Building it:** [docs/BUILD.md](docs/BUILD.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Questions, bugs and feature requests:** open a GitHub issue in this repository. For a
  bug, include the version (`/etc/runink-os-version`), the hardware, what you expected and
  what happened, and remove hostnames, addresses and credentials from any logs
  ([CONTRIBUTING.md](CONTRIBUTING.md#reporting-bugs)).
- **Security problems:** never in a public issue. Follow [SECURITY.md](SECURITY.md).
- **Code of Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Support is best effort by the maintainers in [MAINTAINERS.md](MAINTAINERS.md). There is no
mailing list or chat channel yet. Applications and platforms that others ship on Runink
River as downstream payloads are supported by their vendors, not here.
